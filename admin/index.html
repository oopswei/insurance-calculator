管理者登入

管理者帳號需先在 Supabase Auth 建立，再將該帳號的 User UID 加入 admin_users 資料表。一般註冊帳號不會自動取得管理權限。

CSV 欄位：rate_year,age,male_rate,female_rate。每個年度需包含 0～99 歲共 100 筆資料。匯入同一年度會更新該年度資料，不會影響其他年度。

理賠案例管理

新增或修改案例。圖片可一次選取多張 JPG／PNG／WebP；每個案例可有多張圖片。首頁會自動依分類顯示。

已建立案例與排序

可拖曳分類標題調整分類順序；拖曳分類內的案例卡片調整案例順序。放開後會自動儲存並同步首頁。
